# Paridhi Shukla - Professional Portfolio

![Portfolio Preview](./artifacts/portfolio/public/og-image.png)

A modern, high-performance portfolio website built to showcase my projects, skills, and professional experience as a Computer Engineering Student and Developer.

## 🚀 Live Demo

[View Live Portfolio](https://paridhi-portfolio-sable.vercel.app/)

## ✨ Features

- **Modern Tech Stack**: Built with React, TypeScript, and Vite.
- **Stunning UI/UX**: Designed with Tailwind CSS, Framer Motion animations, and a sleek dark theme.
- **Interactive 3D Elements**: Custom 3D particle background using Three.js and React Three Fiber.
- **Custom Cursor**: Smooth and interactive custom cursor that adapts to hover states.
- **Responsive Design**: Fully responsive layout that looks great on mobile, tablet, and desktop.
- **SEO Optimized**: Includes meta tags and social open-graph configuration.
- **Accessible**: Semantic HTML and ARIA labels.

## 💻 Running Locally

To run this project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Paridhi21shukla/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   Make sure you have [pnpm](https://pnpm.io/) installed.
   ```bash
   pnpm install
   ```

3. **Start the development server**
   ```bash
   pnpm dev
   ```

4. **Build for production**
   ```bash
   pnpm build
   ```
